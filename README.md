# Mediarama Site

This repository will contain the official website for **Mediarama** at **https://mediarama.gallery**.

Mediarama is a free and open-source, self-hosted photo and video gallery. The project aims to build a modern alternative to traditional gallery software such as Coppermine, with a maintainable architecture, modern media workflows and a clean user experience.

## Current status

The website is intentionally **not being implemented yet**.

Development currently focuses on the Mediarama application itself:

https://github.com/cemfirat/mediarama

Work on the public website should begin when the first functional version of Mediarama is ready to demonstrate, install and use.

## Website direction

The future site is expected to provide:

- a clear introduction to Mediarama
- screenshots and a live demo
- installation and self-hosting information
- documentation
- releases and downloads
- migration information for Coppermine users
- ways to support the project through donations
- optional managed hosting when that service becomes available

## Project model

Mediarama itself is intended to remain free and open source.

Users will be able to host the software themselves. In the future, an optional managed hosting service may provide a paid alternative for people who prefer not to operate their own server.

For now, this repository exists only to reserve and document the direction of the official Mediarama website.
